# 《凌晨四点的宠物医院》可玩原型

当前实现范围：凌晨来电、案件标题、医院到场、等候区人物亮相、秦昭四话题询问、第二诊室五处搜证、图片证物册，以及第一轮询问对象选择。

## 已实现

- 三个开场回答均可选择并汇合到主线；
- 雨声环境音与来电提示音；
- 当前说话者单人半身立绘，旁白和电话特写使用专门场景图；
- 秦昭中央立绘与四周折线话题；
- 五个场景物体热区，未悬停时保持原图，悬停后高亮整个物体；
- 四张独立图片证物，以及左侧卡片、右侧大图说明的证物册；
- 调查器械架后才开放变形缝，三件必查证物齐全后才允许离场；
- 可实际调整的声音、音量、文字速度与背景适配方式；
- 等候区三名相关人的立绘选择画面；
- 桌面与窄屏自适应。

## 本地运行

```bash
npm install
npm run dev
```

默认访问：`http://localhost:4173/`
