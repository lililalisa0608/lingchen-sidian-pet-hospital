# 《凌晨四点的宠物医院》可玩原型

当前实现范围：从凌晨来电到完整结案与片尾，包括三轮调查、三处搜证、人物询问、唐宁与苏青的多阶段证言对质、最终指认和案件收束。

## 继续开发前

先阅读 [`PROTOTYPE_UI_CONTRACT.md`](./PROTOTYPE_UI_CONTRACT.md)。其中固化了当前已确认的 PC 与手机端布局、人物立绘标尺、询问页、搜证页、人物选择、弹层交互，以及每次改动后的最低验收矩阵。除非产品需求明确改变，后续章节应复用这套基线。

## 已实现

- 三个开场回答均可选择并汇合到主线；
- 雨声环境音与实体音频来电／推进／开关门／调查／证物提示音，并可在设置中逐项试听；
- 当前说话者单人半身立绘，相关人物在情绪转折台词切换克制的表情差分，旁白和电话特写使用专门场景图；
- 秦昭中央立绘与四周折线话题；
- 五个场景物体热区，未悬停时保持原图，悬停后高亮整个物体；
- 十一张独立图片证物，以及左侧卡片、右侧大图说明的证物册；
- 调查器械架后才开放变形缝，三件必查证物齐全后才允许离场；
- 可实际调整的声音、音量、文字速度与背景适配方式；
- 等候区三名相关人的立绘选择画面与自由顺序的四话题询问；
- 隔离间四处必查热点、林夏第二轮询问，以及血迹鉴定后的证物更新；
- 进入质疑前的标题动效与提示音、复用标准对话框的四句证言前后切换、当前句追问／质疑、四首可即时试听切换的专属 BGM、证物出示、错误反馈与两轮时间线推理；
- 等候区第三轮四热点搜证、三段直播回看、猫毛鉴定更新、苏青四话题再次询问，以及“安静的直播／镜头之外／撞击时间／冲突原因”完整终局对质；
- 苏青认罪、旺旺治疗记录收束、“完”画面、雨后片尾与可重新体验的终幕；
- 背景图使用高质量轻量 JPEG，并按当前／下一场景优先、其余场景空闲时串行预载，减少首次与切场等待；
- 桌面与窄屏自适应。

## 本地运行

```bash
npm install
npm run dev
```

默认访问：`http://localhost:4173/`
